# ataeoncognition.com

Website of ATAEON Cognition Pvt. Ltd., hosted on GitHub Pages.

- Pages: `index.html`, `research.html`, `products.html`, `solutions.html`, `company.html`, `404.html`
- **Add news, research areas, papers or products:** edit `assets/data.js` only.
- Styles: `assets/site.css` · Header/footer + interactions: `assets/site.js`
- Animated logo: `assets/logo.js` · 3D background: `assets/bg3d.js`
- Custom domain: `CNAME`

Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000
